# Структура сайта abit

## Карта страницы (одна страница, якорные секции)

1. **Header** — логотип, навигация, переключатель темы.
2. **Hero (#top)** — заголовок, лид, кнопки CTA, ключевые метрики.
3. **Почему ИТиАД (#why)** — три карточки с преимуществами.
4. **Практика (#practice)** — путь студента, таймлайн, чипы направлений.
5. **Партнёры (#partners)** — сетка производственных партнёров.
6. **Программы (#programs)** — направления подготовки из data/programs.js.
7. **FAQ (#faq)** — вопросы абитуриентов из data/faq.js.
8. **CTA (#admission)** — финальный призыв подать согласие.
9. **Footer** — краткая информация и ссылки.

## Источники данных

- `js/data/partners.js` — редактируется при изменении партнёрской сети.
- `js/data/programs.js` — редактируется при изменении направлений/программ.
- `js/data/faq.js` — редактируется при добавлении новых вопросов приёмной комиссии.

## Принцип рендера

`main.js` при загрузке страницы находит контейнеры по data-атрибутам
(`data-render="partners"`, `data-render="programs"`, `data-render="faq"`)
и рендерит карточки из соответствующих JS-массивов. Это позволяет менять
контент без правок в HTML/CSS.
