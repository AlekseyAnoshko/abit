# abit — сайт для абитуриентов ИТиАД ИРНИТУ

Статический сайт-лендинг для приёмной кампании Института информационных технологий и анализа данных (ИТиАД) ИРНИТУ.

## Структура проекта

```
abit/
├── index.html          — главная страница
├── css/
│   ├── tokens.css       — дизайн-токены (цвета, шрифты, отступы)
│   ├── base.css         — базовые стили и сброс
│   └── components.css   — стили секций и компонентов
├── js/
│   ├── main.js           — тема, интерактив, рендер данных
│   └── data/
│       ├── partners.js   — список партнёров
│       ├── programs.js   — направления подготовки
│       └── faq.js        — вопросы и ответы абитуриентов
├── assets/
│   └── icons/            — иконки/логотип (инлайн SVG в HTML)
└── docs/
    └── structure.md       — карта сайта и описание блоков
```

## Как запустить

Открыть `index.html` в браузере — сайт статический, сборка не требуется.
Для локального сервера: `npx serve .` или любой статик-сервер.

## Наполнение контентом

Отредактируйте файлы в `js/data/` — партнёры, программы, FAQ подгружаются в разметку автоматически через `main.js`.
